A make.fun micro entry for [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) — one funny line a hopeless tech support agent says to a desperate customer.

## The entry

> Have you tried turning it off and on again? Please say yes, it's the last line on my script, and after that we're both on our own.

The joke twists the classic reboot question: the agent is not being helpful, they are begging the customer to say yes because the script runs out right there. The cheerful uselessness is the agent's, not the customer's — after that line, both of them are on their own.

## How it works

`main.py` writes the line to `/output/entry.txt` and prints it. It contains no network calls, no secrets, and no dependencies beyond the Python standard library. The entry is 130 characters long, inside the competition's 1–199 character gate, and two local runs produced byte-identical output.

Run it with:

```sh
python3 main.py
```
